# Game design references

Local research clones live in `reference/checkouts/` (ignored; upstream histories/assets are not vendored).

- `awesome-gpt-6-astra`: https://github.com/MartinDelophy/awesome-gpt-6-astra — curated discovery index. Each work has its own licensing.
- `surge-for-oinja`: https://github.com/Olivia295/SURGE-for-Oinja — exploration objectives, enemy roles and upgrade pacing. Read-only design reference; no copied source or assets.
- Understory: https://understory-gamma-silk.vercel.app/ — inspected playable build: atmospheric forest depth, restrained HUD, journey framing. No public source/license established, so no copied artwork/code/audio.

Wildwood uses original simulation and procedural scene art, generated title art and Duy's existing pet sprites.

- `last-beacon`: https://github.com/stackloomdev/last-beacon — MIT, spatial combat warnings and contextual HUD; already credited as a separate guest game. Wildwood is a new Pets simulation rather than a reskin of its tower defense.
