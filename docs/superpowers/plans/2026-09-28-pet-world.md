# Pixel Pet World Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Build a standalone `/pets` hatchery where a ready-to-play persistent pixel world supports eggs, pets, housing, item production, evolution, and an active combat mini-game.

**Architecture:** Share a versioned save through a small client provider mounted in the root layout. Keep catalog, save migration, economy, evolution, and arena simulation in pure TypeScript modules; render the four page areas and arena client-side without adding a game dependency.

**Tech Stack:** Next.js App Router, React, TypeScript, CSS/SVG pixel art, Canvas 2D, localStorage, existing Motion and i18n.

**Spec:** `docs/superpowers/specs/2026-09-28-gracie-companion-design.md`

## Global Constraints

- `/pets` is separate from the portfolio home; Gracie remains visible throughout public pages.
- Initialize a furnished, interactive starter save only when no valid local save exists; never reset on route changes or reloads.
- Keep Home, Shop, Factory, and Arena visible and accessible from the first visit; no mandatory tutorial or grind gate.
- Use original art and credit/link `https://github.com/leduy-it/portfolio-clone` as a reference only; that checked repository contains no pet assets.
- Keep combat playful and non-graphic, support touch and keyboard, and reduce decorative effects under reduced-motion preference.

## Review Focus

- Invalid, old-version, unavailable, or quota-limited local storage must fall back safely without wiping a valid save.
- Repeated clicks, route changes, refresh, and visibility changes must not duplicate factory rewards or reset an active save.
- Collision updates must avoid repeated multi-hit damage in one frame and stop when the arena is inactive.
- Egg hatching, evolution, and currency rewards must be deterministic and impossible to collect twice from one action.
- Mobile controls and browser zoom must not make the arena or shop inaccessible.

## File Structure

- `src/data/pets/catalog.ts`: pet, egg, item, evolution, and factory-drop definitions.
- `src/lib/pets/save.ts`: versioned save schema, starter save, validation, migration, and safe storage serialization.
- `src/lib/pets/progression.ts`: hatch, collect, place, earn, and evolve state transitions.
- `src/lib/pets/arena-engine.ts`: frame-independent movement, enemy pursuit, attack cooldown, collisions, health, waves, and rewards.
- `src/lib/pets/pet-save-provider.tsx`: root client provider and persisted state actions.
- `src/components/pets/`: pixel sprite, room grid, egg hatch, shop, factory, evolution card, arena canvas, touch controls, and status HUD.
- `src/app/pets/page.tsx`: standalone tabbed hatchery entry and metadata.
- `src/app/layout.tsx`: mount the provider and global Gracie consumer.
- `src/data/i18n-strings.ts`: English/Vietnamese page and game text.
